# Reader

The app runs in the browser. The user reads a book there and picks the actions.

- [ ] The page text shows in a book-like font with a comfortable line length.
- [ ] The actions show below the text, and the user picks one by clicking it.
- [ ] If a page has an [image](images.md), it shows with the text.
- [ ] The user can go back to an earlier page, as described in the
      [book tree](book-tree.md).
- [ ] If a page is a dead end, the reader says so and offers to go back.
- [ ] While the agent writes a new page, the reader shows that it is working.
