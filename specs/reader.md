# Reader

The app runs in the browser. The user reads a book there and picks the actions.

- [x] The page text shows in a book-like font with a comfortable line length.
- [x] The actions show below the text, and the user picks one by clicking it.
- [x] If a page has an [image](images.md), it shows with the text.
- [x] The book has a cover page before page 1. It shows the title, the cover
      image, the genre, the style and the author style.
- [x] The cover page has a button to start reading from page 1, and a button to
      continue from where the reader left off, if that is past page 1.
- [x] If the user opens a book that is still on page 1, the book opens on the
      cover page.
- [x] Going back from page 1 and starting over both go to the cover page.
- [x] The user can go back to an earlier page, as described in the
      [book tree](book-tree.md).
- [x] If a page is a dead end, the reader says so and offers to go back.
- [x] While the agent writes a new page, the reader shows that it is working.
