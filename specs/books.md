# Books

The app holds several books. Each book is a separate story with its own
settings, so the app can write different kinds of books.

## Choosing a book

- [ ] At the start, the user picks a book from the list of books, or creates a
      new one.
- [ ] If the user opens a book, the adventure continues in that book.
- [ ] The books are separate. Pages, [world data](world-data.md) and the
      [book tree](book-tree.md) of one book do not affect another book.

## Book settings

- [ ] When creating a book, the user picks its genre, such as fantasy or science
      fiction.
- [ ] The user picks the style of the book, such as easy-going, grimdark or
      young adult.
- [ ] The user picks the language of the book: English or Finnish. The language
      cannot be changed after the book is created.
- [ ] The agent writes the pages and the actions in the language of the book.

## Author style

- [ ] When creating a book, the user can pick an author whose style the agent
      tries to imitate. The author is optional.
- [ ] The app suggests authors that fit the language, genre and style of the
      book.

## Open questions

- Are genre and style picked from fixed lists, typed in freely, or both?
- Can the user type in an author who is not in the suggestions?
